## 🌟 Portfolio Overview & Structure

This interactive web application provides the complete **Sprint 1 Final Submission**, deconstructing India's Virtual Labs initiative across 5 systemic milestones and projecting 10 grounded innovations for 2031.

### 1. Pre-Sprint Foundational Research (Differentiated Dropdown)
* **Platform Architecture & Boundaries:** High-level ecosystem definition, 175+ labs, 1,590+ experiments, user roles, core workflow, and system boundaries.
* **Case Study 1 (Light Microscopy — Three Modes, Different Barriers):** 250 students, 100 teachers across Animation, Simulation, and Remote Microscope modes with interactive Table 4 search and filter.
* **Case Study 2 (Remote Labs in South Indian Villages — Access as Resource Allocation):** 150 postgraduate students with interactive friction distribution (scheduler 66.7%, execution delays 60%, buffering 50%).

`[▼] SPRINT 1: Full System Baseline & Speculative Horizon`
* **1.1 Sectoral Ecosystem Canvas:**

  * Interactive Network Map Viewer.

## 🚀 How to Run Locally

To preview the website on your local machine:
```bash
python serve.py
```
This automatically starts a local HTTP server at `http://localhost:8080/index.html` and opens your browser.

## 🌐 How to Deploy to GitHub Pages for Live Submission

1. **Initialize Git & Push:**
   ```bash
   git init
   git add .
   git commit -m "Sprint 1 Final Submission: Complete System Baseline & 10 Innovation Ideas"
   git branch -M main
   git remote add origin https://github.com/<your-username>/sprint1-virtual-labs.git
   git push -u origin main
   ```
2. **Enable GitHub Pages:**
   * Open your GitHub repository in your browser.
   * Go to **Settings ➔ Pages**.
   * Under **Build and deployment**, select `Deploy from a branch`, choose branch `main` and folder `/ (root)`, and click **Save**.
3. **Submit on Google Classroom:**
   * Your live submission URL will be:
     `https://<your-username>.github.io/sprint1-virtual-labs/`
